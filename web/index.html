搜索语法

直接输入中文、英文牌名或规则文字。多个条件用空格连接，也可以使用下面的高级语法。

name: / o: / t:牌名 / 规则文字 / 类别（含超类别及副类别）
c: / ci:牌面颜色 / 标识色，支持 =、<=、>=
mv<=3 / m:{G}法术力值比较 / 法术力费用
a:"Rebecca Guay"画家
pow>=2 tou<=4力量与防御力范围，支持负数与小数
set: / cn:系列代码 / 收藏编号
r: / lang:稀有度 / 版本语言
f:commanderEDH 合法卡牌
is:translated / is:untranslated已有中文规则 / 待补中文规则
tag:抓牌功能标签，当前覆盖范围见数据说明
order:edhrec / order:usd按 EDHREC 热度 / USD 价格排序
AND / OR / - / ( )组合、任选、排除、条件分组
