# Magic card symbols

The SVGs are original files from [Scryfall’s Card Symbols API](https://scryfall.com/docs/api/card-symbols), retrieved on 2026-11-14. Each filename and download URL comes from the `svg_uri` in the [Scryfall symbology list](https://api.scryfall.com/symbology). `symbol-files.js` maps the API’s symbol identifiers to the corresponding local SVGs.
