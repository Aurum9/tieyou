# 牌库 · EDH ATELIER

面向中文玩家的万智牌卡查与 EDH 组牌工作台，当前为 V0.1 试用版。

## 运行

使用 Node.js 20+，无前端安装或构建步骤。

```text
npm start
```

打开终端给出的地址，默认 http://127.0.0.1:4173/。

`dist/` 可以直接部署到静态托管服务。卡库和标签随站点分片加载，卡图在线访问 Scryfall；用户卡组使用当前浏览器本地存储。

## 已实现

- 默认首页为卡组库，先读取浏览器本地卡组记录，不下载完整卡库；打开编辑器或导入牌表时按需加载卡牌数据，同页复用。
- 独立卡查入口继续保留。空搜索不显示卡牌，输入有效查询或筛选后按需加载；清空查询和筛选后恢复空白搜索页。
- 中英文名称、规则文字搜索；简略／高级筛选切换，隐藏后仍生效的高级条件以角标、保留提示和可移除标签展示。
- 基础卡牌颜色与高级标识色独立筛选，均支持任一、全部、恰好、仅在所选范围内四种关系；法术力值提供含边界的上下限，留空不限，支持 0 和小数。
- 高级模式提供真实 Scryfall 功能标签，支持任一／全部关系与完整词表输入建议；系列代码及名称也提供输入建议。
- 可视化编辑所有支持字段及 AND／OR／NOT、嵌套条件组，文字自动安全转义；主搜索框保留手写高级语法。
- 多牌面详情、中英对照与印刷版本选择；系列、编号、稀有度和语言按同一印刷版本组合匹配。
- 卡组新建、编辑、复制、删除恢复，统帅／主牌／候选牌分区、数量、选版、分类和备注。
- 卡组编辑器支持卡名自动补完，输入时显示前 8 个候选，点击查找最多显示 50 个；候选直接加入当前卡组主牌区，添加后保留搜索内容。
- 编辑器的高级搜索携带当前卡组、搜索词及主将标识色限制，跳转后展开高级筛选。卡查加牌直接写入该卡组主牌区，返回后保留编辑器；编辑器内详情加牌也使用当前编辑卡组。
- 独立卡查上方提供目标卡组开关及选择栏；选定后各加牌入口直接加入目标主牌区，未选择或清除选择后，点击加入显示原有卡组／分区选择窗口。
- 卡名、系列编号、搜索结果三种加牌入口；卡组内搜索默认按已选主将的标识色并集限制，包含无色，并可手动取消限制。无色主将仅显示无色标识牌，无主将时不限。
- 文本导入的逐行检查、歧义修正与明确跳过，文本及完整 JSON 导出。
- JSON 原子新增恢复，浏览器保存失败提示与损坏存储保护。
